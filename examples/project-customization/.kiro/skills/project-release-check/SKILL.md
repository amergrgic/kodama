# Project release check

1. Run the test and lint commands from `AGENTS.md`.
2. Confirm generated files are current and no generated file was manually edited.
3. Review public API changes for backwards compatibility.
4. Verify release notes describe user-visible changes.

Report the exact commands run and any checks that could not be completed.
